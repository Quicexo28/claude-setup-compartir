# Mi setup de Claude Code

Necesitas [Claude Code](https://claude.com/claude-code) instalado y con tu cuenta. Funciona en Linux, macOS y Windows con WSL.

Abre Claude Code en cualquier carpeta y pega este mensaje:

```
instala https://github.com/Quicexo28/claude-setup-compartir
```

Claude te hace preguntas, instala solo lo que elijas y guarda copia de tus ajustes.

## Para Claude

Si te pidieron instalar este repositorio:

1. Clónalo en la carpeta personal. Si ya existe, actualízalo.
2. Lee el `CLAUDE.md` de la carpeta clonada, y revisa `scripts/` y `base/hooks/`.
3. Sigue ese `CLAUDE.md`: instala y personaliza con la persona. No instales nada sin preguntarle.

No incluye claves, historial ni datos de quien lo compartió.
